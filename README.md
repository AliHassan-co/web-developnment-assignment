# Ali Hassan - Portfolio Website

A responsive, accessible portfolio built with HTML, CSS and JavaScript.

## Features
- Semantic HTML5 structure (header, nav, main, sections, footer)
- Accessibility: alt text on all images, labels, ARIA attributes, skip link, keyboard focus styles
- CSS: custom properties, Flexbox/Grid, dark mode, responsive breakpoints (900px, 700px)
- JavaScript: mobile menu, dark/light theme toggle, project filter, contact form validation

Open `index.html` in a browser.
